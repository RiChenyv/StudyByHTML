# PHP 学习手册 · 从零到 CTF

一份单文件、可离线使用的交互式 PHP 学习指南，面向网络安全方向的学习者：从语法入门一路讲到 CTF Web 的常见考点。

## 使用方法

直接用浏览器打开 `PHP学习手册.html` 即可，无需服务器、构建或联网。

## 内容大纲

- **环境搭建**：官方 PHP + 内置服务器、phpstudy、Docker 三种方案
- **语法基础**：变量与弱类型、字符串、数组、运算符、流程控制、函数、类、命名空间、魔术方法
- **运行模型**：一次请求的生命周期、超全局变量、`$_FILES` 结构、Session
- **代码执行（RCE）**：危险函数、变量函数、回调型入口、过滤绕过、`disable_functions`
- **文件包含**：LFI 攻击路径、系统敏感目录地图、RFI、`php://filter` 详解
- **文件上传**：黑名单绕过思路速览
- **弱类型与比较**：`==` / `===` 差异、MD5 碰撞与数字截断、`preg_match` 绕过
- **反序列化**：序列化格式、魔术方法、`__wakeup` 绕过、POP 链、`phar://` 反序列化
- **进阶技巧**：包装器速查、变量覆盖、无字母数字 Webshell、`open_basedir` 绕过

## 特性

- 深色 / 浅色主题切换
- 代码高亮与一键复制
- 内置搜索与速查表，适合刷题时快速查阅
