网安学生 vs 后端开发：学 PHP 的根本区别

⚠️ ?: 和 ?? 别混（面试/审计高频）

两个都读作「取默认值」，但语义不同：短三元 ?: 判断的是「假值」——空串、'0'、0 都会回退，且键不存在照样报警告；null 合并 ?? 只在「键不存在或值为 null」时回退，且不报未定义索引（内部自动 isset）。

请求$_GET['level'] ?: 0$_GET['level'] ?? 0差异说明
?level=3'3''3'都有值，结果一致（注意都是字符串）
?level=0''空串算假值 → ?: 回退；?? 保住空串
?level=00'0''0' 算假值 → 两者都是 0，但类型不同
无参数0 + Warning0?: 报未定义索引，?? 静默

CTF 意义：题目用 ?: 时，传空串能把值「消掉」回到默认（常用于绕开等值判断）；用 ?? 时空串会保留——传空串看回显差异，可以反推后端用的是哪个。取值后一律强转防坑：(int)($_GET['level'] ?? 0)，?level=abc 也安全变 0。可链式：$_GET['a'] ?? $_SESSION['a'] ?? 0，从左到右取第一个非 null。

CHAPTER 03
🏛️ 面向对象：为反序列化打好地基
目标：看懂类定义；记住每个魔术方法的「触发时机」。这是第 10 章反序列化的前置技能。

类的最小集合

::class 与命名空间（读框架源码的前置）

ℹ️ 为什么 CTF 必须懂这个

① 手工写反序列化 payload 时类名要写全名（含命名空间，如 O:17:"AppModelsLogger":...），写短了就是 __PHP_Incomplete_Class；② 框架题的 gadget 类都埋在 vendor 深处，找链第一步就是确认命名空间路径；③ 「类名来自用户输入」的代码（new $c()、$c::method()）等于任意类实例化入口，审计必盯。

ℹ️ 序列化格式里的可见性（第 10 章伏笔）

serialize 输出里，protected 属性名前有 \x00*\x00 前缀，private 属性名前有 \x00类名\x00 前缀，public 没有。构造 POP 链 payload 时写错可见性 = 反序列化失败。

魔术方法：对象的生命周期钩子（★★★）

以 __ 开头的方法在特定时机自动触发，不需要手动调用。反序列化漏洞的本质就是：让攻击者构造的对象在销毁/输出/调用时自动执行危险代码。

🎯 读反序列化题的万能套路

拿到源码先扫一遍所有类里的魔术方法，然后问三个问题：① 入口在哪（哪里 unserialize）？② 哪个魔术方法里有危险动作（eval/system/include/file_put_contents…）？③ 怎么从入口的自动触发「接力」到危险方法——这条接力路线就是 POP 链。第 10 章手把手走一遍。

① 用户请求

调试三板斧（读题必备）

  • var_dump() 万能打印：类型、长度、数组结构全出来。
  • highlight_file(__FILE__)：很多题直接把源码染色输出，先通读。

⚠️ 两个常见陷阱

① $_SERVER['QUERY_STRING'] 是原始未解码的查询串，?a=%73ystem 不会被还原，绕过基于它的过滤时很关键；② PHP 对参数名的清洗规则：空格、.、[（不在成对 [] 里时）会被换成下划线，a.b→a_b，但 a[b.c] 的键保留 b.c——老题考过用这个差异绕过参数名白名单。

CHAPTER 05
💀 命令执行：system 一家子
目标：认全命令执行函数；掌握拼接符号与常见过滤绕过。

先立世界观：RCE 的两种「执行」

RCE（Remote Code Execution，远程代码执行）= 让目标服务器执行攻击者的代码或命令。Web 漏洞危害的最高一档：拿到它 ≈ 拿到服务器 shell——读写任意文件、拖库、提权驻留、以服务器为跳板横向进内网。

说法执行什么对应函数
命令执行操作系统命令（ls、cat）system · exec · shell_exec · passthru · popen · 反引号 —— 本章
代码执行PHP 代码eval · assert（旧版）· call_user_func · 回调族 —— 第 6 章

实际场合常混称 RCE，结局一样：你的指令在别人机器上跑起来了。

RCE 的四条来路（漏洞升级图）

  • 命令拼接（本章主题）：sy«stem»("ping " . $_GET['ip'])——输入里塞 ; | && 或反引号，拼接结果就变成两条命令。
  • 文件上传 → webshell：传 .php 文件（第 4 章 $_FILES、第 7 章绕过），访问即执行。
  • 反序列化 → POP 链：链子终点落在调用 system/eval 的 gadget 上（第 10 章）。
  • 文件包含 → 日志 / session / 图片马：让 include 指向藏了代码的文件（第 7 章）。
💡 防御一句话

能不调 shell 就不调（用 PHP 原生库）；必须调则白名单校验参数（filter_var($ip, FILTER_VALIDATE_IP)）或 escapeshellarg() 包裹，禁止拼接；永远不要 eval 用户可控内容；纵深防御靠 disable_functions + 最小权限。

危险函数全家福

函数行为返回
system($cmd)执行并直接输出结果末行文本（可不要）
exec($cmd, &$out)执行，结果进 $out 数组末行文本（不自动输出！）
shell_exec($cmd)执行完整输出字符串（不自动输出）
passthru($cmd)执行并原样输出（适合二进制）无
反引号 ` $cmd `等价 shell_exec同 shell_exec
popen($cmd,'r')开管道，配 fread 读结果文件指针
proc_open更精细的进程控制资源
pcntl_exec($path,$args)替换当前进程执行程序（需 pcntl 扩展，多见于 Linux CLI）不返回
💡 echo 检查法

题目里 exec/shell_exec 不回显结果？——把你的 payload 换成回显型的：?cmd=ls 用 system 就直接看得见；如果只有 shell_exec，试试外带（curl/dnslog）或写文件 > 1.txt 再想办法读。

回调收到几个参数？（挑执行函数的依据）

💡 三条审计细节

① 回调写法不止字符串：'类::静态方法'、[对象, '方法'] 都是合法 callable，审计时同样要盯；② 语言结构不能当回调——eval、include、echo 是语言结构不是函数，塞进回调位置直接报错（想任意代码执行得绕道旧版 assert 之类）；③ 别背函数清单，背形状：手册参数类型标 callable 的位置 + 用户输入流入 = 任意函数调用点。

🔓 反序列化：从入门到 POP 链
目标：看懂序列化格式；理解魔术方法触发链；掌握 __wakeup 绕过；知道 phar 为何危险。

序列化格式：像读 JSON 一样读它

读法口诀：字母:值；s:4:"flag" = 长度 4 的字符串；对象 O:类名长:"类名":属性数:{键;值;键;值;}。改 payload 就是改这些数字和字符串，改完长度必须同步改。

漏洞原理：30 秒讲清

ℹ️ 关键认知

反序列化漏洞不是「unserialize 执行了代码」，而是你控制了对象的属性，程序里的魔术方法拿着这些属性替你干活。所以找漏洞 = 在源码里找「属性 → 危险动作」的搬运工。

__wakeup 绕过（CVE-2016-7124）

版本条件：PHP < 5.6.25 或 PHP < 7.0.10。原理：序列化串中声明的属性个数大于真实属性个数时，__wakeup 不触发，直接跳到后续流程。

POP 链：魔术方法接力赛

当代码没有直接「属性→危险函数」时，就让多个类的魔术方法互相触发：A 的 __destruct 调用属性对象 B 的方法 → 触发 B 的 __toString → 读取 B 中属性对象 C 的不存在属性 → 触发 C 的 __get → 最终走到 eval/system。起点通常是 __destruct/__wakeup，终点是危险函数，中间靠 __toString/__call/__get/__invoke 传动。

💡 抠链技巧

① 从终点倒着找：先定位 eval/system/include 在哪个类，看它在哪个魔术方法里；② 再找谁能「摸到」这个类（谁 echo 它/调用它/访问它的属性）；③ 拼装时注意 protected/private 的 \x00 前缀，浏览器框里手打 \x00 不行，用 urlencode 传输。构造完 urlencode(serialize($obj)) 一次性搞定。

phar:// 反序列化（无 unserialize 也能打）

phar 是 PHP 的打包格式。元数据（metadata）以序列化对象存储——当文件函数通过 phar:// 协议访问 phar 包时，PHP 会自动 unserialize 元数据，魔术方法就此引爆。即使代码里一个 unserialize 都没有。

受 phar 影响的常用函数

gethostbyname simplexml_load_file（XML 反序列化另一路）

① 全局搜 __destruct / __wakeup / __toString 定位入口类 → ② 顺着方法体看它调用了哪个属性上的什么方法 → ③ 把该属性值换成下一个类的对象，接力直到落到 system/eval/file_put_contents → ④ 手写序列化串（注意 private/protected 的 前缀与字符串长度）。

php://filter 详解（★必背）

filter 写马：死亡 exit 的破解完整版

🎯 2024 新贵：iconv filter 链 RCE

研究发现在较新的 PHP 环境里，链式堆叠 convert.iconv.* 过滤器可以伪造出任意内容（php filter chain）——只要 include/file_get_contents 可控，无需上传任何文件即可 RCE。生成器搜「php_filter_chain_generator」。先掌握常规用法，见到「无文件写入点但可 include」的题再回来深造。

php://input 与 data://

💡 场景速查

读源码 → filter+base64；RCE（allow_url_include 开） → php://input 或 data://；后缀拼接 → zip/phar 子路径；文件存在性判断 → phar 反序列化。拿到任意文件参数，按这个顺序挨个试。

CHAPTER 12
🃏 冷门特性、无字母 RCE 与版本差异
目标：变量覆盖 / 参数名解析 / 无字母数字 webshell / open_basedir / 版本时间线。

变量覆盖全家桶

无字母数字 Webshell（专治 preg_match 字母数字全禁）

思路：不出现字母数字，用位运算/自增把可用字符「造」出来。

💡 取反速算

字符 x 的取反 = 255 - ASCII(x)。比如 s(115) → 140 → \x8c。本地写个循环生成即可，别手算。生成后 urlencode 传输。第 14 章的工具箱内置了「取反」按钮，直接用。

open_basedir 绕过速览

open_basedir 限制 PHP 只能访问指定目录。绕过姿势：① glob:// 协议列目录（不受限制）：glob:///flag*；② chdir()+ini_set() 动态改 basedir；③ 伪协议 compress.zlib:// 读文件；④ 利用命令执行类（系统调用不受 basedir 限制）；⑤ symlink 软链接（老版本）。

杂项彩蛋（遇到认得出就行）

  • $_SERVER['PHP_SELF'] 直接拼进 HTML → XSS（URL 路径里注入脚本标签）。
  • header('Location: '.$_GET['url']) → CRLF 注入 / 开放重定向。
  • 短标签：<?= 永远可用；<? ... ?> 需 short_open_tag；<script language="php"> 和 ASP 风格 7.0 移除。
  • .phps 后缀 = 源码染色输出（配置开启时泄露源码）。
  • PHP 整数溢出：PHP_INT_MAX 之后转 float，intval 溢出绕过数值比较。
  • ** 幂运算、<=> 太空船、??=：见题查手册即可。

版本时间线：一图流断代

PHP 5.2 及以前
上古题。magic_quotes 自动转义 GET/POST；%00 截断可用（<5.3.4 修复）。
PHP 5.3~5.6
ereg 正则（吃数组报错）；preg_replace /e 可用；assert 字符串可执行；create_function 可用。反序列化 __wakeup 绕过版本边界（<5.6.25）。
PHP 7.0~7.1
preg /e 移除；__wakeup 绕过边界（<7.0.10）；弱类型依旧全开。
PHP 7.2~7.4
create_function 弃用（8 移除）；assert 不再执行字符串（7.2 起 warning，8 fatal）；CTF 出题主力版本。
PHP 8.x
松散比较收紧（0=="abc" false）；字符串函数吃数组直接 TypeError（md5 数组绕过失效）；create_function 移除；8.2 动态属性弃用（不影响 unserialize 老写法但会 warning）。
⚠️ 实战第一问

拿到 PHP 题，先想办法确认版本：flag 附近报错页、phpinfo、X-Powered-By 响应头、payload 行为差异（比如 md5 数组绕过是否 500）。版本定错，绕过思路全废。

🕹️ 互动实验室：5 道模拟真题
每关模拟一个真实题目环境（PHP 7.4 / Linux），输入 payload 点「提交」，模拟器会判定是否拿到 flag。先自己试，再看提示和解答。
通关进度 0 / 5
LAB 01命令执行 · 严格过滤未通过
🎯 目标：拿到 /flag 文件内容。环境：Linux + PHP 7.4，flag 就在 /flag。
等待你的 payload…（模拟器会按 URL 解码处理 %xx）
过滤了所有「命令连接符号」，但 system 执行的是 shell 命令——shell 里除了符号，还有什么字符也能开启新命令？想想换行。URL 传参时换行怎么写？（形如 127.0.0.1%0a某命令）
payload：?ip=127.0.0.1%0acat%20/flag
原理：URL 编码的 %0a 会在 $_GET 解析时变成真实换行符；shell 收到换行即认为开始新命令，绕过了所有符号过滤。若 cat 也被过滤，用 c""at、tac、more 等价替换；空格被过滤则 cat</flag 或 ${IFS}。
LAB 02弱类型 · md5 双响炮未通过
🎯 目标：同时满足两个条件拿到 flag（PHP 7.4）。两种解法都试一试！
等待你的参数…
两条路：① 找两个 md5 值都是 0e 开头数字串的值（第 8 章魔术哈希）；② 让 md5() 吃到它处理不了的东西，两次返回一样的东西（数组？）。参数名别忘了怎么传数组。
解法一：a=240610708&b=QNKCDZO（md5 后 0e462... 与 0e830...，== 数值比较 0==0 过）
解法二：a[]=1&b[]=2（md5(数组) 返回 null，null==null 过；数组之间 !== 过）。模拟器两种都认。
LAB 03文件包含 · 读源码未通过
🎯 目标：flag 藏在 flag.php 的源码里，直接包含看不到，读出它的源码（base64 形式即算成功）。
等待你的参数…
include flag.php 只会执行它（无输出）。想「看见」源码而不是「执行」它，需要一个不会解析 PHP 的通道——第 11 章的读过滤器。resource 前面套什么？
payload：file=php://filter/read=convert.base64-encode/resource=flag.php
读出的 base64 解码即是源码。变体：string.toupper、iconv 过滤器链；读别的文件（/etc/passwd）用相对或绝对路径。
LAB 04反序列化 · wakeup 绕过未通过
🎯 目标：让 __destruct 输出 /flag（环境 PHP 5.6，存在 CVE-2016-7124）。
等待你的序列化串…（可以用上一章的 serialize 可视化生成，再手动改造）
正常 payload 会被 __wakeup 改回 index.php。PHP 5.6 存在一个著名 CVE：当序列化串里的属性个数和真实不符时 wakeup 失效。改哪个数字？
payload：u=O:6:"Secret":2:{s:4:"file";s:5:"/flag";}
把属性个数 1 改成 2（任意大于 1 的数）。__wakeup 跳过 → __destruct 读 /flag。若题目没给 CVE 条件，只能从 __destruct 之外找链（POP）。
LAB 05无字母数字 RCE未通过
🎯 目标：构造不含任何字母（a-z A-Z）和数字的 PHP 代码，实现执行系统命令。
等待你的 payload…
$ _ ; ( ) = ~ ^ + . ! 这些字符都可用。第 12 章三法：取反/异或/自增。取反最省事：目标函数名的每个字节取反后都不是字母数字。第 14 章工具箱的「取反」按钮可以直接生成。
payload 思路（取反）：把 system 六个字符各自取反拼成 \x 字符串赋给变量，再把命令串同样取反构造，最后以变量函数形式调用。模拟器接受任何「无字母数字且含取反/异或/自增构造并出现执行调用」的合理 payload。
