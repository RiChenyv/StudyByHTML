# Linux 入场 · 四天 AWD 学习手册

直接用浏览器打开 `index.html`，无需安装依赖、构建或启动服务器。请保留同目录下的 CSS 和 JS 文件。旧的 `Linux基础14天学习计划.html` 会自动跳转到新版入口。

## 学习路线

1. 认识终端，守住文件：命令结构、目录、阅读、文件操作和可验证备份。
2. 读懂日志，理解权限：find / grep、日志字段、管道统计、身份和权限。
3. 把 PHP 与 HTTP 接起来：本地站点、GET / POST、进程端口、响应与错误日志。
4. 完成一轮 AWD 防守闭环：基线、留证、最小恢复、业务验证和复盘。

全站提供 57 条独立命令的常见参数、示例与误区，116 个术语解释，以及 64 道挑战（48 道命令输入、16 道场景判断）。不使用外部字体、脚本、图片或页面跳转，也没有资源导航。

手册里的命令输入只进行判题，不执行系统命令。可执行实验使用 `setup-lab.sh`：在 Ubuntu / Debian 的 Bash 中建立自己的 `~/awd-lab`，不修改系统设置、不安装软件、不启动服务；已存在目标目录时拒绝覆盖。PHP 站点只绑定本机回环地址。初始化脚本和实验步骤都可在“开始前的准备”中阅读。

## 文件说明

- `index.html`：页面入口和无障碍基础结构。
- `styles.css`：桌面、移动端、深浅主题与打印样式。
- `content.js`：课程、命令、词典和操作清单。
- `challenges.js`：题库及不执行输入的有限判题器。
- `app.js`：导航、搜索、筛选、弹窗、答题和本地进度。
- `setup-lab.sh`：贯穿四天的本地 PHP 实验和健康检查脚本。
- `verify.cjs`：命令引用、题库完整性、大小写及引号等回归检查。

## 校验

在仓库根目录执行 `node LinuxStudy/verify.cjs`，无需第三方依赖。脚本语法可用 `bash -n LinuxStudy/setup-lab.sh` 检查。学习进度使用浏览器 localStorage，键为 `linux-awd-v2`；主题键为 `linux-awd-theme`。旧版进度不会误计入新课程。

本次验证覆盖桌面 1440px、手机 390px / 320px、十个路由、检索筛选、术语嵌套弹窗、持久化、看答案不计通过、深浅主题、file 离线入口及零外部请求。实验在本机 GNU Bash 与 PHP 8.5 中验证初始化拒绝覆盖、归档恢复隐藏文件、日志统计、GET / POST、PHP 语法故障、留证恢复及“HTTP 200 但正文错误”判失败。Linux 特有权限、systemd、网络管理命令需在相应 Linux 环境练习，本机 Windows 验证不代替这些操作。
